# Documento: Visión y Alcance del Proyecto

## 1. Objetivos del Documento
Definir los límites, el propósito de negocio y el alcance del Producto Mínimo Viable (MVP) para la tienda web **Almacenes al Costo**.

## 2. Alcance
*   **Dentro del Alcance**: Venta de muebles, electrodomésticos y artículos para el hogar; checkout inteligente sin cuenta; pasarela de pagos en línea (desacoplada para Stripe, PayPhone, Datafast, Kushki, etc.); validación manual de pagos (Transferencia y Deuna); panel administrativo responsivo con estados de pago integrados.
*   **Fuera del Alcance**: Sistema de facturación electrónica automática; app móvil nativa.
