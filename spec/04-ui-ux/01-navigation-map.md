# Documento: Mapa de Navegación y Transición de Pantallas

## 1. Objetivos del Documento
Estructurar de manera lógica el mapa de navegación del sitio web y los flujos visuales que experimenta el usuario.

## 2. Mapa de Navegación

### Flujo de Navegación del Cliente
*   **Inicio** (Landing) -> **Catálogo** (Filtros y Búsqueda) -> **Detalle del Producto** -> **Carrito** (Modal o Vista) -> **Checkout** -> **Confirmación del Pedido** -> **Método de Pago** -> **Subir Comprobante** -> **Confirmación Final** -> **Crear Cuenta (Opcional)**.

### Flujo de Navegación del Administrador
*   **Login Admin** -> **Dashboard** (Inicio)
*   **Dashboard** -> Sidebar de Accesos Directos:
    *   Gestionar Productos / Formulario de Producto.
    *   Gestionar Categorías.
    *   Gestionar Inventario.
    *   Gestionar Pedidos / Detalle de Pedido (Validación).
    *   Gestionar Clientes.
    *   Gestionar Promociones.
    *   Reportes Básicos.
    *   Configuración General.
