# Documento: Sistema de Diseño e Identidad Visual

## 1. Objetivos del Documento
Establecer los lineamientos de diseño visual, colores, tipografía y adaptabilidad para crear una interfaz premium y moderna para **Almacenes al Costo**.

## 2. Lineamientos Visuales
*   **Marco de Trabajo**: Bootstrap 5 (CSS Vanilla para adaptaciones finas).
*   **Tipografía**: Fuente principal de Google Fonts: *Outfit* o *Inter* (para un look limpio, moderno y de alta legibilidad comercial).
*   **Colores Premium (Nueva Identidad Gráfica)**:
    *   *Fondo Principal*: Crema cálido y limpio (`#FDFBF7` o `#FAF6F0`).
    *   *Color Principal (Brand)*: Naranja cálido y vibrante (`#E25822` o `#F26419`).
    *   *Color Secundario*: Durazno / Melón suave (`#F7A072` o `#F8AD9D`).
    *   *Color de Textos*: Café oscuro elegante (`#3D312A` o `#4F3C35`) para un contraste óptimo.
    *   *Tarjetas e Indicadores*: Marfil refinado (`#FCFAF2` o `#FAF9F6`).
    *   *Acciones Principales (Botones)*: Naranja, con transiciones suaves a Durazno en estado *Hover*.
*   **Estilo Visual e Inspiración**:
    *   Inspiración en plataformas modernas de retail de electrodomésticos y tecnología (ej. Artefacta, Créditos Económicos, La Ganga).
    *   Bordes marcadamente redondeados en contenedores, inputs y botones (`border-radius: 12px` a `16px`).
    *   Sombreados suaves y difuminados para dar volumen y jerarquía (`box-shadow: 0 8px 16px -4px rgba(61, 49, 42, 0.08);`).
*   **Enfoque de Pantalla**:
    *   *Público*: Diseño Mobile-First muy depurado, adaptado para compras rápidas por teléfono.
    *   *Admin*: Diseño Dashboard-Grid para visualización cómoda de grandes listados de datos y tablas de pedidos.
